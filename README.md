# HealthConnect Rwanda — Week 6 Data Analytics Package
AnalystLab Africa Experience Lab | Track 1: Data Analytics

## What this package contains
- 40 PostgreSQL query templates aligned to the official Week 6 SQL tasks.
- KPI dictionary and data validation checklist.
- Executive report template and PowerPoint presentation framework.
- Power BI dashboard design guide and starter DAX measures.
- Workbook for recording results once the healthcare database is available.

## Important source limitation
The available source file was the official Week 6 assignment brief. The 27 healthcare data tables / CSVs or a PostgreSQL database backup were not present in the available files when this package was assembled. Consequently, the queries have not been executed against real project data and no patient, clinical, financial, or facility results have been fabricated. Table and column names in SQL are proposed mappings inferred from the brief and must be checked against the actual schema.

## Before submission
1. Add the actual supplied datasets to Data/ (use de-identified data only).
2. Confirm table and column names in SQL against PostgreSQL information_schema.
3. Execute queries and record real outputs in the workbook.
4. Build and test the native Power BI .pbix in Power BI Desktop.
5. Export the final dashboard to PDF and replace the report template with evidence-based results.
6. Confirm all recommendations against validated results and organizational context.

## Privacy and safety
Do not upload identifiable patient data to public repositories. Use access controls, de-identification, minimum necessary data, and approved storage.
